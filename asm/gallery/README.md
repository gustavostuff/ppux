# Gallery ROM (ca65)

CNROM oversize (iNES mapper 3), 32 KB PRG, 16 x 8 KB CHR banks.

## Layout

```
asm/gallery/
  Makefile
  nes.cfg
  README.md
  gallery.nes  # generated
  s/           # assembly sources (.s)
  o/           # object files (.o) - generated
  data/
    chr/       # slideNN.chr (8KB) - generated by PPUX
    nam/       # slideNN.nam (1024B) - generated by PPUX
    pal/       # slideNN/main.pal (32B) - generated by PPUX
```

## Build

```bash
make -C asm/gallery
```

Needs `ca65` / `ld65` (cc65) on `PATH`. Missing `data/chr` / `data/nam` / `data/pal` bins are filled automatically.

## Controls

Controller 1 **Left** / **Right** - previous / next slide (edge-triggered).

## Palettes

Per-slide blobs in `data/pal/slideNN/main.pal` (`.incbin` from `s/palette.s`):

- BG rows: `07 17 27 36` x 4 (or from linked sketch palette)
- Sprite rows: `07 0F 0F 0F` x 4 (color 0 matches BG backdrop; `$3F10` mirrors `$3F00`)

## PPUX

App top toolbar **Generate gallery ROM** (`nes_generate_gallery_rom` icon, before Relocation pointer calculator):

1. Confirm modal lists packed sketch canvases in window order (slides)
2. On Confirm, `SketchCanvasGalleryRomController.buildGalleryRom(app, sketches)`:
   - Writes `data/chr/slideNN.chr`, `data/nam/slideNN.nam`, `data/pal/slideNN/main.pal`, and `s/slide_meta.s`
   - Runs `make -C asm/gallery clean all`
   - Copies `gallery.nes` beside the loaded ROM as `{stem}_gallery.nes`
3. Result modal reports success (path) or failure
